2 MB XML on a 1 MB Microcontroller

Question

Pen and paper. Nothing is compiled, randomised or marked for you. Set the timer, answer, then compare with the solution sheet.

10:00 Allotted: 10 minutes

The scenario

A microcontroller has 1 MB of RAM.

It must read an XML file that is 2 MB.

Your task

  1. Say how the device reads the file.
  2. Draw the data flow from the file to the application.
  3. Label each link with what is passed.
