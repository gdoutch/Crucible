Polling the meter

ItemChoice
RequestFunction 0x03 or 0x04 for the active-power registers. One request, contiguous registers
RateEvery 200 ms to 1 s. Fast enough for the control loop, slow enough for the bus speed
FramingRTU: a 3.5-character silent gap ends a frame
IntegrityCRC-16/MODBUS on every reply. Check the address, function code and byte count too
TimeoutAbout 100 to 200 ms per request. Count misses
DecodingSigned 32-bit, often two registers. Word order differs between meters, so make it configuration

The control loop

  1. Grid power is measured, with export negative (or positive, by convention; pick one and enforce it).
  2. Headroom = limit − current export − margin.
  3. New maximum discharge = current inverter output + headroom.
  4. Slew-limit the change, so the loop does not oscillate.
  5. Send the result to the sandbox as a limit, with a lease.

The limit is on the site, not the battery. The house load changes all the time, so the battery's allowance changes with it. That is why it is a loop and not a fixed setting.

When the meter stops answering

ConditionResponse
One bad CRC or timeoutRetry on the next poll. Keep the last value
Reading older than a few secondsTreat as unknown. Force the limit to a value that cannot breach export, for example zero discharge
Reading out of rangeDiscard it. Count it as a miss
Persistent lossStay in the safe limit. Raise a fault to the cloud

The easy miss is the sign convention. A current transformer fitted backwards flips import and export, and the limiter then pushes the wrong way. Check it at commissioning: turn the battery on and see which way the reading moves.

Point to raise

The export-limitation rules in your market set the response time and the fail-safe behaviour. In Great Britain, for example, that is G100. Read them before choosing the timeouts.

Self-marking checklist

  • Modbus master drawn in the coordinator, not the sandbox?
  • CRC and timeout checked on every reply?
  • Word order and sign convention mentioned?
  • Control loop uses headroom, not a fixed limit?
  • Slew limiting mentioned?
  • Stale reading forces a safe limit?
