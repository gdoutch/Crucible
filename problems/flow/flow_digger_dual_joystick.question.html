Digger Drive Control: Seat and Console Joysticks

Question

Pen and paper. Nothing is compiled, randomised or marked for you. Set the timer, answer, then compare with the solution sheet. This builds on Digger Drive Control, so do that one first.

Allotted: 30 minutes

The scenario

A digger has a seat that can rotate (north / south).

The seat joystick is fixed to the armrest, so it turns with the operator. Its reading is relative to the operator.

There is also a console joystick, fixed to the console and always facing forward (north).

Drive direction and gear selection depend on the state of these inputs:

  • Seat north: the console joystick is the master controller. The seat joystick also works.
  • Seat south: the console joystick is disabled.

Your task

  1. Draw the component diagram, with both joysticks.
  2. Label each link with the data passed.
  3. Give the arbitration rule: for every seat position and every joystick state, which input drives the machine, and in which direction?

Stretch prompts

Only if time remains.

  • What if both joysticks are deflected, in different directions, with the seat north?
  • What if the console joystick is deflected while the seat is south?
  • What happens to a console joystick that is held while the seat rotates?
  • What if one joystick fails, or its message is lost?
