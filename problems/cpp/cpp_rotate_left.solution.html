Rotate a Vector Left by k

Worked solution

This page contains the complete answer and explains why each part of it is there.

The code

#include <algorithm>
#include <vector>

void RotateLeft(std::vector<int>& values, long long k)
{
    if (values.empty())
    {
        return;
    }
    long long n = static_cast<long long>(values.size());
    long long shift = ((k % n) + n) % n;
    std::rotate(values.begin(), values.begin() + shift, values.end());
}

Why ((k % n) + n) % n

In C++ the result of % takes the sign of the left operand, so a negative k gives a negative remainder. Adding n lifts it into [0, 2n) and the second % folds it into [0, n); for a non-negative k the extra steps change nothing. Doing the arithmetic in long long also keeps a huge k from overflowing a 32-bit int.

Cost

O(n) time, O(1) extra space.
