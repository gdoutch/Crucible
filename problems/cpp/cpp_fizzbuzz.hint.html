FizzBuzz as a Function

Hint

A nudge in the right direction. The full answer is on the worked-solution page, so nothing below gives it away.

Most specific case first

if (/* divisible by 3 and 5 */) return "FizzBuzz";
if (/* by 3 */) return "Fizz";
if (/* by 5 */) return "Buzz";
return std::to_string(n);

Each if returns, so order is everything: the combined case has to be asked before either single one. Try 15, 30 and 45 by hand against your branch order before you run anything.

Where it goes wrong

Order of the tests is the only difficulty. A number divisible by 15 satisfies the by-3 test and the by-5 test as well as the combined one, so if either single test is asked first, 15 answers "Fizz" or "Buzz" and the combined branch is dead code. Also remember the plain case returns text: the function's return type is std::string, so a bare number will not do.
