Minimum and Maximum in One Pass

Worked solution

This page contains the complete answer and explains why each part of it is there.

The code

#include <utility>
#include <vector>

std::pair<int, int> MinMax(const std::vector<int>& values)
{
    int lo = values[0];
    int hi = values[0];
    for (std::size_t i = 1; i < values.size(); i++)
    {
        if (values[i] < lo) { lo = values[i]; }
        if (values[i] > hi) { hi = values[i]; }
    }
    return {lo, hi};
}

Why seed from values[0]

The running minimum and maximum must always be values that are in the array. values[0] is the one element guaranteed to exist, so it is the only safe starting point; every later element can then only replace it with something genuinely smaller or larger. A literal 0 (or INT_MAX / INT_MIN sentinels, which fail on an array made of those very values) can report a number the caller never supplied.

Cost

O(n) time, one pass, O(1) extra space. Two separate std::min_element / std::max_element calls (or the single std::minmax_element) are equally correct.
