Clamp Every Element In Place

Worked solution

This page contains the complete answer and explains why each part of it is there.

The code

#include <vector>

void ClampAll(std::vector<int>& values, int lo, int hi)
{
    for (int& x : values)
    {
        if (x < lo) { x = lo; }
        else if (x > hi) { x = hi; }
    }
}

Why int& x

A range-for binds its loop variable by copy unless you say otherwise. for (int x : values) is perfectly valid and perfectly useless here: x = lo modifies the local copy and the vector never sees it. int& makes x an alias for the element itself.

Cost

O(n) time, O(1) extra space. The one-liner x = std::clamp(x, lo, hi); inside the same loop is equivalent.
