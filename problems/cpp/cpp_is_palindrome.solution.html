Palindrome, Ignoring Punctuation

Worked solution

This page contains the complete answer and explains why each part of it is there.

The code

#include <cctype>
#include <string>

bool IsPalindrome(const std::string& text)
{
    int left = 0;
    int right = static_cast<int>(text.size()) - 1;
    while (left < right)
    {
        while (left < right && !std::isalnum(static_cast<unsigned char>(text[left])))
        {
            left++;
        }
        while (left < right && !std::isalnum(static_cast<unsigned char>(text[right])))
        {
            right--;
        }
        if (std::tolower(static_cast<unsigned char>(text[left])) !=
            std::tolower(static_cast<unsigned char>(text[right])))
        {
            return false;
        }
        left++;
        right--;
    }
    return true;
}

Why the inner loops repeat the bound check

After skipping, left and right may have met or crossed. Without left < right in the skip loops, a punctuation-only string drives left past right (and off the end of the string). Guarding them keeps both indices in range and makes the "no letters at all" case fall through to true.

Why the unsigned char cast

The <cctype> functions are defined only for values representable as unsigned char (or EOF). A negative char passed straight in is undefined behaviour.

Cost

O(n) time, O(1) extra space.
