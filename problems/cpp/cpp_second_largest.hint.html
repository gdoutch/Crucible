Second Largest Distinct Value

Two running values, both optional

std::optional<int> best, second;
for (int v : values) {
    // new maximum: old best becomes second
    // strictly between: improves second
    // equal to best: ignore
}
return second;

Whenever a new maximum arrives, the old maximum is demoted to second place. A value equal to the maximum changes nothing.

Where it goes wrong

Duplicates are the usual trap: with [9, 9, 5] a naive "track the two biggest values seen" reports 9 twice. The second trap is the starting value. If you begin both running values at INT_MIN, an input that really contains INT_MIN cannot be told from "nothing found". Use the optional type the signature already gives you to carry that state.
