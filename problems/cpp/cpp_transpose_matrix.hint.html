Transpose a Matrix

Hint

A nudge in the right direction. The full answer is on the worked-solution page, so nothing below gives it away.

Build a new matrix with the dimensions swapped

t = C rows, each of R columns
for i in 0..R-1:
    for j in 0..C-1:
        t[j][i] = m[i][j]

Reading m[i][j] and writing t[j][i] is the whole idea. The only care needed is in sizing t and in the empty case. Sketch a 2 x 3 matrix on paper and write down the shape of its transpose before you write the allocation.

Where it goes wrong

Sizing is where this goes wrong. The result of an R x C matrix has C rows, each R long; allocate it R x C and any non-square input writes out of bounds. Swapping elements within the original works only for a square matrix, and even then swapping every pair twice undoes the work. An empty matrix has no first row to measure.
