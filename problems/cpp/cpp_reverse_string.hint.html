Reverse a String in Place

Hint

A nudge in the right direction. The full answer is on the worked-solution page, so nothing below gives it away.

Two indices, walking inward

int left = 0;
int right = static_cast<int>(text.size()) - 1;
while (left < right) {
    // swap text[left] and text[right]
    left++;
    right--;
}

Nothing needs to be allocated: every character already lives inside text, and reversing it is just a matter of exchanging pairs of characters from the outside in.

The signature is the whole point

Look closely at the parameter: std::string&, not std::string. Drop the & and the function still compiles, still runs, and still appears to "work" when you test it by printing something inside the function -- it is only from the *caller's* side that the bug shows up, because the caller's own string was never touched. If your function signature doesn't match the one given in the starter code exactly, that is the first thing to check.

std::swap(text[left], text[right]) exchanges the two characters directly through the reference -- there is no need to read them into temporaries yourself first.
