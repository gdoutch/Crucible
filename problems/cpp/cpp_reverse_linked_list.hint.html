Reverse a Singly Linked List

Hint

A nudge in the right direction. The full answer is on the worked-solution page, so nothing below gives it away.

Three pointers, one loop

Node* prev = nullptr;
Node* current = head;
while (current != nullptr) {
    // save current->next somewhere BEFORE overwriting it
    // point current->next backwards, at prev
    // advance prev and current
}
return prev;

The order these three steps happen in is the entire exercise

The moment current->next is reassigned to point at prev, the original value it held -- the pointer to the rest of the list -- is gone unless something already saved it. Reassign first and read current->next afterwards to "advance", and what you read back is prev, the node you just rewired to, not the node that used to come next. The rest of the original list becomes unreachable, permanently, with no crash to announce it -- on a two-node list this can accidentally look fine; it stops looking fine the moment there is a third node.

By the time the loop ends, current is nullptr and prev is sitting on the last node the loop visited -- the new head. Return prev, not current.
