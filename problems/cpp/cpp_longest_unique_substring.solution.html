Longest Substring Without Repeating Characters

Worked solution

This page contains the complete answer and explains why each part of it is there.

The code

#include <algorithm>
#include <string>
#include <vector>

int LongestUniqueSubstring(const std::string& text)
{
    std::vector<int> last(256, -1);
    int best = 0;
    int left = 0;
    for (int right = 0; right < static_cast<int>(text.size()); right++)
    {
        unsigned char c = static_cast<unsigned char>(text[right]);
        left = std::max(left, last[c] + 1);
        last[c] = right;
        best = std::max(best, right - left + 1);
    }
    return best;
}

Why max(left, last + 1)

last[c] remembers the most recent position of c anywhere in the string, not just inside the current window. In "abba" the final 'a' was last seen at index 0, but by then the window has already moved to start at index 2 because of the repeated 'b'. Assigning left = last['a'] + 1 = 1 would drag the left edge backward over the two 'b's and report a length of 3. Taking the maximum means a stale record can never pull the window back.

Why every character is visited once

right only moves forward and so does left; neither is ever reset. That is what makes the whole thing linear, in contrast to the brute-force approach that re-scans from each starting point.

Why unsigned char

The table is indexed by character value. A char above 127 is negative on common platforms; converting to unsigned char first keeps the index in 0..255.

Cost

O(n) time, O(1) extra space (a table of 256 entries).
