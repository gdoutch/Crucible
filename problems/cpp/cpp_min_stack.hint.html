A Stack That Knows Its Minimum

Hint

A nudge in the right direction. The full answer is on the worked-solution page, so nothing below gives it away.

Remember the minimum at every depth

push: mins.push_back( min(value, mins.empty() ? value : mins.back()) )
pop:  mins.pop_back()   // in step with values
Min:  mins.back()

Store, alongside each value, the minimum of everything at or below that depth. Popping then restores the old minimum for free, because the entry underneath already holds it.

Where it goes wrong

The tempting design is one int currentMin. It fails the moment you pop the minimum: the value underneath was the previous minimum, and a single variable has forgotten it. The other classic slip is recording only strictly smaller values, which loses a duplicate minimum -- push 2 twice, pop once, and the minimum must still be 2. Whatever history you keep has to move in lock-step with values on every push and pop.
