Group Words by Length

Worked solution

This page contains the complete answer and explains why each part of it is there.

The code

#include <map>
#include <string>
#include <vector>

std::map<std::size_t, std::vector<std::string>>
GroupByLength(const std::vector<std::string>& words)
{
    std::map<std::size_t, std::vector<std::string>> groups;
    for (const std::string& w : words)
    {
        groups[w.size()].push_back(w);
    }
    return groups;
}

Why there is no existence check

map::operator[] default-constructs a missing value (an empty vector here) and hands back a reference to it. That turns "create the group if needed, then append" into the single expression groups[w.size()].push_back(w). Walking the words in order and appending is also what preserves their relative order inside each group.

Cost

O(n log k) for n words and k distinct lengths (one map lookup per word), plus the cost of copying the strings.
