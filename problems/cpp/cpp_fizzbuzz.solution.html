FizzBuzz as a Function

Worked solution

This page contains the complete answer and explains why each part of it is there.

The code

#include <string>

std::string FizzBuzz(int n)
{
    if (n % 15 == 0)
    {
        return "FizzBuzz";
    }
    if (n % 3 == 0)
    {
        return "Fizz";
    }
    if (n % 5 == 0)
    {
        return "Buzz";
    }
    return std::to_string(n);
}

Why 15 goes first

A number divisible by 15 is divisible by 3 and by 5, so it satisfies every one of the three tests. Whichever test is written first wins, which means the most specific one must come first. n % 15 == 0 is the same condition as n % 3 == 0 && n % 5 == 0.

Why std::to_string

The fall-through case must return text. std::to_string(int) formats the number in decimal, including negative values and the largest int, so no manual digit loop is needed.

Cost

O(1): a handful of remainder operations whatever n is.
