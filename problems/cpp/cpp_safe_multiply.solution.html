Multiply Without Signed Overflow

Worked solution

This page contains the complete answer and explains why each part of it is there.

The code

#include <climits>

bool SafeMultiply(int a, int b, int& result)
{
    long long wide = static_cast<long long>(a) * static_cast<long long>(b);
    if (wide < INT_MIN || wide > INT_MAX)
    {
        return false;
    }
    result = static_cast<int>(wide);
    return true;
}

Why check before multiplying

Because signed overflow is undefined, int p = a * b; if (p / b != a) is not a valid test: the multiplication has already invoked UB, and a compiler may assume it did not and optimise the test away. The only safe shape is to prove the product is in range without forming an out-of-range int.

Why widening works

long long holds at least 64 bits, and two 32-bit values multiply to at most about 262, so static_cast<long long>(a) * b cannot overflow. Comparing against INT_MIN and INT_MAX then answers "does it fit?" exactly, including INT_MIN * -1 (which is 2147483648, one past INT_MAX) with no special-casing.

Without widening

You can stay in int by comparing against INT_MAX / b and INT_MIN / b with the sign of each operand handled separately; zero must be filtered out first, and INT_MIN / -1 must itself be avoided because it overflows.

Cost

O(1).
