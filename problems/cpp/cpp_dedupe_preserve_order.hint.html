Remove Duplicates, Keep First-Seen Order

Hint

A nudge in the right direction. The full answer is on the worked-solution page, so nothing below gives it away.

One set, one pass, one append

std::vector<int> result;
std::unordered_set<int> seen;
for (int v : values) {
    if (seen.insert(v).second) {
        result.push_back(v);
    }
}
return result;

One call answers two questions

seen.insert(v) returns a std::pair<iterator, bool>, and the .second is true exactly when v was not already in the set -- the insert happens either way, so by the time you read .second the value is already recorded for next time. There is no need for a separate seen.count(v) check before the insert: that would be asking the same question twice, once explicitly and once as a side effect of inserting.

Do not sort values, and do not iterate seen itself to build the answer -- an unordered_set's own iteration order has nothing to do with insertion order. The output has to be built by walking values, which is the only place the "first appeared" order actually lives.
