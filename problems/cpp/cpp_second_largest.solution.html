Second Largest Distinct Value

Worked solution

This page contains the complete answer and explains why each part of it is there.

The code

#include <optional>
#include <vector>

std::optional<int> SecondLargest(const std::vector<int>& values)
{
    std::optional<int> best;
    std::optional<int> second;
    for (int v : values)
    {
        if (!best || v > *best)
        {
            second = best;
            best = v;
        }
        else if (v < *best && (!second || v > *second))
        {
            second = v;
        }
    }
    return second;
}

Why optional, not a sentinel

Initialising the two running values to INT_MIN makes a vector containing INT_MIN indistinguishable from "not found yet". An optional carries the missing state separately from the value, so every int stays usable. The same type is what lets the function report "no second value" without inventing a magic number.

Why equal values are skipped

The else if (v < *best ...) test is strict, so a repeat of the maximum falls through both branches and leaves second alone.

Cost

O(n) time, O(1) space.
