Run-Length Encoding

Hint

A nudge in the right direction. The full answer is on the worked-solution page, so nothing below gives it away.

Measure a run, write it, jump past it

while (i < text.size()) {
    j = i;
    while (j < text.size() && text[j] == text[i]) j++;
    // append text[i] and the number (j - i)
    i = j;
}

Finding the whole run in an inner loop means there is no "previous character" state to flush at the end. For the count, think about what j - i is once the inner loop stops, and which standard function turns a number into its decimal text.

Where it goes wrong

Most wrong answers lose the final run, because the code writes a run only when it sees a character that differs from the previous one, and the last run is never followed by a different character. Counts above 9 are the second trap: a12 needs a real conversion to text, not a single character. Finally, an empty line must not index the first character.
