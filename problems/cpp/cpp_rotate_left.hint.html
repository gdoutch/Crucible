Rotate a Vector Left by k

Hint

A nudge in the right direction. The full answer is on the worked-solution page, so nothing below gives it away.

Get k into [0, size) before doing anything

if (values.empty()) return;
long long n = values.size();
long long shift = ((k % n) + n) % n;   // always in [0, n)
std::rotate(values.begin(), values.begin() + shift, values.end());

The empty-vector guard has to come before the %. The + n and second % turn a possibly-negative remainder into the matching non-negative one.

Where it goes wrong

Three edge cases decide this one. An empty vector: taking k % 0 is undefined behaviour, so return first. A negative k: C++'s % keeps the sign of the left operand, so -1 % 5 is -1, and using that as an offset walks off the front of the vector. A huge k: it is a long long for a reason, so do the reduction in long long before narrowing to an index.
