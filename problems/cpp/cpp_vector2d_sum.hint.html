Sum Vectors With operator+

Hint

A nudge in the right direction. The full answer is on the worked-solution page, so nothing below gives it away.

It reads like an ordinary function, because it is one

Vector2D operator+(const Vector2D& a, const Vector2D& b) {
    return Vector2D{a.x + b.x, a.y + b.y};
}

An operator overload is a function with an unusual name (operator+) and an unusual calling convention (a + b instead of operator+(a, b), though both actually work) -- everything else about writing one is exactly like writing any other function that takes two const Vector2D& and returns a new Vector2D.

The signature has to match exactly

The problem asks for this specifically as a free function, matching the declaration Vector2D operator+(const Vector2D& a, const Vector2D& b); that the harness forward-declares and calls. A member-function overload (Vector2D Vector2D::operator+(const Vector2D& other) const) also makes ordinary a + b expressions compile in code that has access to both the definition and the call site together -- but it is a *different* overload from the free function the harness expects to link against, and a build that produces one without the other fails at the link step, with no line of your own code to point at.
