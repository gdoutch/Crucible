A Stack That Knows Its Minimum

Worked solution

This page contains the complete answer and explains why each part of it is there.

The code

#include <algorithm>
#include <vector>

struct MinStack
{
    std::vector<int> values;
    std::vector<int> mins;
};

void Push(MinStack& s, int value)
{
    int m = s.mins.empty() ? value : std::min(value, s.mins.back());
    s.values.push_back(value);
    s.mins.push_back(m);
}

void Pop(MinStack& s)
{
    s.values.pop_back();
    s.mins.pop_back();
}

int Min(const MinStack& s)
{
    return s.mins.back();
}

Why a parallel stack

mins[i] holds the minimum of values[0..i]. Pushing appends min(value, mins.back()); popping removes the top of both vectors. Because the entry beneath already summarises everything beneath it, the earlier minimum reappears without any search. A single variable, or a stack that only records new strict minima, cannot do this -- it either forgets history or mishandles duplicates of the minimum.

Cost

All three operations are O(1); extra space is one int per element.
