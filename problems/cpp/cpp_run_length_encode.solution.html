Run-Length Encoding

Worked solution

This page contains the complete answer and explains why each part of it is there.

The code

#include <string>

std::string RunLengthEncode(const std::string& text)
{
    std::string out;
    std::size_t i = 0;
    while (i < text.size())
    {
        std::size_t j = i;
        while (j < text.size() && text[j] == text[i])
        {
            j++;
        }
        out += text[i];
        out += std::to_string(j - i);
        i = j;
    }
    return out;
}

Why an inner loop

The single-loop version -- compare each character with the previous one and write when they differ -- needs a special case for the very first character and another after the loop for the final run, and forgetting either is the usual bug. Measuring each run completely before writing it makes both disappear: an empty string never enters the loop, and the last run ends when j reaches text.size().

Why std::to_string

out += count with a char or small integer appends a character code, not digits, and cannot represent counts above 9 anyway.

Cost

O(n) time; output is at most twice the input length.
