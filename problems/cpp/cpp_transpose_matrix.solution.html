Transpose a Matrix

Worked solution

This page contains the complete answer and explains why each part of it is there.

The code

#include <vector>

std::vector<std::vector<int>>
Transpose(const std::vector<std::vector<int>>& m)
{
    if (m.empty())
    {
        return {};
    }
    std::size_t rows = m.size();
    std::size_t cols = m[0].size();
    std::vector<std::vector<int>> t(cols, std::vector<int>(rows));
    for (std::size_t i = 0; i < rows; i++)
    {
        for (std::size_t j = 0; j < cols; j++)
        {
            t[j][i] = m[i][j];
        }
    }
    return t;
}

Why a new matrix

An R x C matrix and its C x R transpose do not have the same shape unless R == C, so there is nothing to swap in place. Allocating C rows of R columns and copying m[i][j] to t[j][i] works for every rectangle; sizing the result as R x C instead writes outside the vector the first time the matrix is not square.

Why check empty() first

m[0].size() on an empty outer vector is undefined behaviour.

Cost

O(R x C) time and space.
