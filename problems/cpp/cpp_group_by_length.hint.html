Group Words by Length

Hint

A nudge in the right direction. The full answer is on the worked-solution page, so nothing below gives it away.

operator[] makes the group for you

std::map<std::size_t, std::vector<std::string>> groups;
for (const std::string& w : words) {
    groups[/* the length */].push_back(w);
}
return groups;

No find, no if (contains): indexing a missing key inserts an empty vector and returns a reference to it, so push_back works on the very first word of each length.

Where it goes wrong

Two ways to get this subtly wrong. Sorting or de-duplicating the words changes the order inside a group or drops repeats, and both are visible in the tests: to be or not to be must keep every occurrence, in the order read. And a hand-written "does this key exist yet?" branch is not just verbose, it is where the first-word-of-each-length bug usually hides. Let the map create the entry for you.
