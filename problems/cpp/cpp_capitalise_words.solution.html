Capitalise Each Word

Worked solution

This page contains the complete answer and explains why each part of it is there.

The code

#include <cctype>
#include <string>

std::string Capitalise(std::string text)
{
    bool startOfWord = true;
    for (char& c : text)
    {
        unsigned char u = static_cast<unsigned char>(c);
        if (c == ' ')
        {
            startOfWord = true;
        }
        else
        {
            c = static_cast<char>(startOfWord ? std::toupper(u) : std::tolower(u));
            startOfWord = false;
        }
    }
    return text;
}

Why a flag instead of splitting

Splitting on whitespace (istringstream >> word) throws away how many spaces separated the words and any leading or trailing ones, and rejoining with a single space gives a different string. A single pass over the characters with a "start of word" flag changes only the letters and leaves every space exactly where it was.

Why unsigned char

std::toupper and std::tolower are defined only for values that fit in unsigned char (or EOF); a negative char from a non-ASCII byte is undefined behaviour.

Cost

O(n) time, no extra string.
