Capitalise Each Word

Hint

A nudge in the right direction. The full answer is on the worked-solution page, so nothing below gives it away.

A flag for "the next letter starts a word"

bool startOfWord = true;
for (char& c : text) {
    if (c == ' ') startOfWord = true;
    else { /* upper or lower by the flag */ startOfWord = false; }
}

The flag is set at the start and again after every space, and cleared after any other character. That is why a digit at the start of a word uses up the capital: "3d" stays "3d".

Where it goes wrong

Splitting into words and rejoining looks tidy but loses the original spacing: runs of spaces collapse, and leading and trailing spaces vanish. The output is printed inside brackets precisely so you can see them. Work character by character instead. Also lower-case the letters that are not at the start of a word -- "hELLO" is not finished by upper-casing the h.
