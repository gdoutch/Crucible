Clamp Every Element In Place

Hint

A nudge in the right direction. The full answer is on the worked-solution page, so nothing below gives it away.

Write through a reference

for (int& x : values) {
    // adjust x
}

Without the &, x is a copy of each element and every assignment to it is thrown away. Compile warnings will not save you -- the code is legal, it just does nothing.

Where it goes wrong

Range-for copies by default. for (int x : values) compiles, runs, and changes nothing -- the assignment lands on a throwaway copy. The signature already takes the vector by non-const reference, so the vector itself is writable; the question is only whether your loop variable is an alias for each element or a copy of it. Also note the function returns void: the harness prints the vector it passed in, so there is nothing to return.
