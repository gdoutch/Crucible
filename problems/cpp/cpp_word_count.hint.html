Count Words With a String Stream

Hint

A nudge in the right direction. The full answer is on the worked-solution page, so nothing below gives it away.

Let the stream do the splitting

std::istringstream stream(text);
std::string word;
int count = 0;
while (stream >> word) {
    count++;
}
return count;

std::istringstream wraps a string in the same interface std::cin has -- and >> into a std::string already means "skip any leading whitespace, then read up to the next run of whitespace or the end of input". That is exactly the definition of a word this exercise is using.

What not to reach for

Splitting on a single literal space character (say, walking the string by hand and cutting at every ' ') has to separately handle runs of more than one space, and separately handle leading or trailing space producing empty "words" at the ends -- three things to get right instead of one. >> already treats a run of whitespace as a single separator and produces nothing at all for leading or trailing whitespace, because that is what extracting a whitespace-delimited token means by definition.
