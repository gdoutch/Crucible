Remove Duplicates, Keep First-Seen Order

Worked solution

This page contains the complete answer and explains why each part of it is there.

The code

#include <unordered_set>
#include <vector>

std::vector<int> DedupePreserveOrder(const std::vector<int>& values)
{
    std::vector<int> result;
    std::unordered_set<int> seen;
    for (int v : values)
    {
        if (seen.insert(v).second)
        {
            result.push_back(v);
        }
    }
    return result;
}

Why `insert(v).second` replaces a separate membership check

std::unordered_set::insert already has to determine whether v is a new element in order to decide whether to actually add it -- that determination is exactly "have I seen this value before", so the return value hands it straight back rather than making the caller ask a second, redundant question with .count(v) or .find(v) first. Reading .second from the pair it returns costs nothing extra: the set has already done the lookup as part of doing the insert.

Why the result is built from `values`, not from `seen`

std::unordered_set makes no promises at all about what order it iterates its elements in -- that order is an implementation detail of its hash table, not something tied to when elements were inserted. The only place "the order values first appeared" is actually recorded is values itself, so the result vector has to be built by walking it directly, appending a value the one time seen.insert reports it as new and skipping it every later time it recurs.

Cost

O(n) average in the length of `values` -- each element does one hash-set insert (O(1) average) and, for a first occurrence, one `push_back` (amortised O(1)).
