Longest Substring Without Repeating Characters

Hint

A nudge in the right direction. The full answer is on the worked-solution page, so nothing below gives it away.

A window and a last-seen table

left = 0
for right in 0 .. n-1:
    left = max(left, last[text[right]] + 1)
    last[text[right]] = right
    best = max(best, right - left + 1)

The window is [left, right] and it never contains a repeat. When the new character was last seen inside the window, left jumps past it; if it was last seen before left, nothing changes.

Where it goes wrong

Two mistakes dominate. The first is complexity: restarting a scan from every starting position is quadratic, and interviewers will ask you to do better. The second is subtler and appears even in a linear solution: setting the left edge to last[c] + 1 unconditionally. That moves the window backward whenever the character's last sighting is already behind the left edge, which is exactly what "abba" exercises. The visible tests include that case and "dvdf"; trace both by hand before you run anything.
