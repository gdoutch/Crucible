Palindrome, Ignoring Punctuation

Hint

A nudge in the right direction. The full answer is on the worked-solution page, so nothing below gives it away.

Two indices, stepping over the noise

int left = 0, right = (int)text.size() - 1;
while (left < right) {
    // advance left past non-alphanumerics
    // retreat right past non-alphanumerics
    // compare tolower of both; mismatch -> false
    left++; right--;
}
return true;

Keep the inner skip loops guarded by left < right too, or a string like "..," will run an index off the end. And cast to unsigned char before calling std::isalnum / std::tolower.

Where it goes wrong

Two things bite here. First, the skip loops: if they do not re-check that the two indices have not met, a string made only of punctuation walks one index straight off the end of the string. Second, the character functions: std::isalnum and std::tolower take an int that must fit in unsigned char, so a plain negative char is undefined behaviour. Cast first. Remember also that digits count, so "0P" is not a palindrome even though '0' and 'P' are both "just characters".
