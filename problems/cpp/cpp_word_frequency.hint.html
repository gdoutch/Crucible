Word Frequency With operator[]

Hint

A nudge in the right direction. The full answer is on the worked-solution page, so nothing below gives it away.

One line, no branch

std::map<std::string, int> counts;
std::istringstream stream(text);
std::string word;
while (stream >> word) {
    counts[word]++;
}
return counts;

This is not the trap it would be in some other languages

If you have used a dictionary/map type elsewhere that throws when you read a missing key, the instinct to reach for a "get-or-default" helper here is understandable -- but `std::map`'s `operator[]` does not throw on a missing key at all. It inserts one, value-initialised (`0` for `int`), and hands back a reference to it. `counts[word]++` on a word's first appearance reads that freshly-inserted `0`, increments it to `1`, and writes it back -- all in the one line, with nothing special about the first occurrence versus the hundredth.

Keep the comparison case-sensitive -- do not lower-case word before counting it.
