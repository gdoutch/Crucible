A Doubly Linked Chain Without Leaks

Hint

A nudge in the right direction. The full answer is on the worked-solution page, so nothing below gives it away.

One owner per node, and it points forward

auto node = std::make_shared<Node>();
node->value = v;
tail->next = node;      // owns forward
node->prev = tail;      // weak_ptr: observes, does not own

Keep a local tail while building so you can link each new node to the previous one. The only shared_ptrs that outlive the function should be the returned head and the chain of next links.

Where it goes wrong

Run your code through the last test in your head: build five nodes, release the head, count the destructors. If every link between nodes owns its target, node 2 is held by node 1 and by node 3, so releasing the head frees nothing and the count stays at zero. Nothing crashes and nothing is printed -- the memory is simply never returned. Decide which direction owns and which merely observes, and look at the types the Node struct already gives you.
