Balanced Brackets With std::stack

Push opens, check-then-pop closes

std::stack<char> open_brackets;
for (char c : text) {
    if (c is an opening bracket) {
        open_brackets.push(c);
    } else if (c is a closing bracket) {
        // is open_brackets empty, or does .top() not match c?
        // either one means "unbalanced" -- return false right here
        // otherwise: read .top(), then .pop()
    }
    // anything else: ignore it entirely
}
return open_brackets.empty();

Two calls, not one

std::stack<char>::pop() returns void -- it removes the top element but does not hand it back to you. If you want to know what was on top *and* remove it, that is .top() (read, without removing) followed by .pop() (remove, without reading) as two separate statements. Calling .pop() and trying to use its result will not compile.

.top() and .pop() on an empty stack are undefined behaviour, not an exception -- check .empty() *before* calling either one, for a closing bracket that arrives with nothing open to match it.
