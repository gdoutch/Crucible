Two pointers, walking inward

int left = 0, right = text.Length - 1;
while (left < right) {
    // if text[left] isn't alphanumeric, left++ and try again
    // if text[right] isn't alphanumeric, right--  and try again
    // otherwise compare them (case-folded) and move both inward
}
return true;

No new string needs to be built to hold "just the letters and digits" -- the two pointers can skip past punctuation in place, one side at a time.

Skip, don't stop

When text[left] is not alphanumeric, the right move is left++; continue; -- try the *next* character on that side, not give up on the comparison. A solution that treats a punctuation character as an automatic mismatch fails on "A man, a plan, a canal, Panama" at the very first comma.

char.IsLetterOrDigit and char.ToLowerInvariant are the two checks doing all the work here -- the first decides what counts as "part of the word", the second makes the comparison case-blind.
