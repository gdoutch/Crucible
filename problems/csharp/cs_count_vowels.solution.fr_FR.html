Compter les voyelles

Solution détaillée

Cette page contient la réponse complète et explique pourquoi chaque partie s'y trouve.

Le code

public static int CountVowels(string text)
{
    int count = 0;
    foreach (char c in text)
    {
        char lower = char.ToLowerInvariant(c);
        if (lower == 'a' || lower == 'e' || lower == 'i'
            || lower == 'o' || lower == 'u')
        {
            count++;
        }
    }
    return count;
}

Pourquoi la normalisation de casse n'a lieu qu'une fois, en amont

char.ToLowerInvariant(c) est calculé une seule fois par caractère et réutilisé pour les cinq comparaisons. L'alternative -- comparer c à dix littéraux, cinq en minuscule et cinq en majuscule -- n'est pas fausse, mais c'est la forme la plus susceptible de ne finir par en couvrir que neuf sur dix dans l'urgence : "CRUCIBLE", tout en majuscules, est le cas de test fixe conçu spécifiquement pour attraper une solution qui ne vérifie discrètement que les minuscules et réussit malgré tout par accident sur une entrée en casse mixte.

Une chaîne vide n'est pas un cas particulier

foreach sur une chaîne vide n'exécute simplement pas son corps, et la fonction retourne 0 sans avoir besoin d'une vérification explicite. Cela mérite d'être remarqué plutôt que supposé : une solution construite autour de l'indexation (text[0] pour regarder le premier caractère, par exemple) doit rajouter la garde pour la chaîne vide à la main, là où la forme foreach n'en a jamais eu besoin.

Coût

O(n) dans la longueur de text -- un seul passage, une normalisation de casse et jusqu'à cinq comparaisons par caractère, aucune allocation.
