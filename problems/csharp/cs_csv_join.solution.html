Join a List Into a CSV Line

Worked solution

This page contains the complete answer and explains why each part of it is there.

The code

public static string JoinCsv(List<string> items)
{
    return string.Join(",", items);
}

Why this needs no special case for empty or single-element lists

string.Join's contract is "place the separator strictly *between* consecutive elements", which already implies both edge cases without any extra code: zero elements means zero separators and an empty result; one element means zero separators (there is no second element to separate it from) and the element itself, unchanged. A hand-rolled loop that appends item + separator after *every* element is answering a subtly different question -- "put a separator after each element" -- which happens to produce the right answer for the *interior* elements and the wrong one at the boundary, needing a trim or an end-of-loop check to correct.

Cost

O(n) in the total length of all the strings involved -- string.Join computes the total output length up front and writes into one buffer, rather than repeatedly reallocating the way result += item in a loop would.
