Min, Max and Sum as a Value Tuple

Hint

A nudge in the right direction. The full answer is on the worked-solution page, so nothing below gives it away.

Seed from the array, not from a constant

int min = values[0];
int max = values[0];
long sum = 0;
foreach (int v in values) {
    // update min, max, sum
}
return (min, max, sum);

Seeding min and max from values[0] means every other element only ever has to prove it is *more* extreme than what has been seen so far -- there is no separate "is this the first element" branch needed inside the loop.

The overflow the return type is already warning you about

sum is declared long in the return type for a reason: accumulating into an int local and only converting to long at the very end (return (min, max, (long)sum);) overflows during the accumulation itself, before the conversion ever runs -- the cast comes too late to save a value that has already wrapped. Declare the running total as long from its first assignment.
