Interleave Two Sequences, Lazily

Two enumerators, advanced in lockstep

using var ea = a.GetEnumerator();
using var eb = b.GetEnumerator();
bool aHasMore = ea.MoveNext();
bool bHasMore = eb.MoveNext();

while (aHasMore || bHasMore) {
    if (aHasMore) {
        yield return ea.Current;
        aHasMore = ea.MoveNext();
    }
    if (bHasMore) {
        yield return eb.Current;
        bHasMore = eb.MoveNext();
    }
}

Why the loop condition is ||, not &&

while (aHasMore && bHasMore) stops the instant either side runs out -- which drops the rest of whichever sequence was longer, exactly the behaviour the statement rules out. || keeps the loop going as long as *either* side still has something left, and the two independent ifs inside it -- each only yielding and advancing its own side when that side still has more -- are what let one side keep contributing after the other has already gone quiet.

aHasMore and bHasMore are read, not recomputed, inside the loop -- each is only ever updated by its own side's MoveNext() call, right after that side yields.
