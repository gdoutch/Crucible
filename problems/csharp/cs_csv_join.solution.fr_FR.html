Assembler une liste en une ligne CSV

Solution détaillée

Cette page contient la réponse complète et explique pourquoi chaque partie s'y trouve.

Le code

public static string JoinCsv(List<string> items)
{
    return string.Join(",", items);
}

Pourquoi cela ne demande aucun cas particulier pour les listes vides ou à un seul élément

Le contrat de string.Join est « placer le séparateur strictement *entre* les éléments consécutifs », ce qui couvre déjà les deux cas limites sans code supplémentaire : zéro élément signifie zéro séparateur et un résultat vide ; un élément signifie zéro séparateur (il n'y a pas de second élément dont le séparer) et l'élément lui-même, inchangé. Une boucle écrite à la main qui ajoute item + séparateur après *chaque* élément répond à une question subtilement différente -- « mettre un séparateur après chaque élément » -- ce qui donne la bonne réponse pour les éléments *intérieurs* et la mauvaise à la frontière, nécessitant une correction ou une vérification en fin de boucle.

Coût

O(n) dans la longueur totale de toutes les chaînes concernées -- string.Join calcule la longueur totale du résultat à l'avance et écrit dans un seul tampon, plutôt que de réallouer sans cesse comme le ferait result += item dans une boucle.
