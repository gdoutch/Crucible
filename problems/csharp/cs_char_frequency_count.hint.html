Character Frequency Count

Hint

A nudge in the right direction. The full answer is on the worked-solution page, so nothing below gives it away.

One line, no branch

var counts = new Dictionary<char, int>();
foreach (char c in text) {
    counts[c] = counts.GetValueOrDefault(c) + 1;
}
return counts;

What breaks if you reach for counts[c]++ instead

counts[c]++ is shorthand for counts[c] = counts[c] + 1 -- and the read half of that, counts[c], throws KeyNotFoundException the very first time c shows up, because there is no entry yet to read. It works fine for the second occurrence of a character onward, which is exactly the kind of bug that survives casual testing on repeated input and only shows up on a string where every character is distinct.

The empty-string case comes for free

foreach over an empty string never runs its body, so the dictionary stays empty and is returned as-is -- no separate check needed for "there was nothing to count".
