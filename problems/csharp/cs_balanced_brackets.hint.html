Push opens, pop-and-check closes

var stack = new Stack<char>();
foreach (char c in text) {
    if (c is '(' or '[' or '{') {
        stack.Push(c);
    } else if (c is ')' or ']' or '}') {
        // is the stack empty, or does Pop() not match c?
        // either one means "unbalanced" -- return false right here
    }
    // anything else: ignore it entirely
}
return stack.Count == 0;

Check before you pop

stack.Peek() and stack.Pop() both throw on an empty stack rather than returning something you can compare against -- guard with stack.Count == 0 *before* calling either one, on a closing bracket that has nothing open to match.

A small map from closing character to the opening character it expects -- ')' → '(', ']' → '[', '}' → '{' -- turns "does this closing bracket match what I just popped" into one dictionary lookup and one comparison, rather than a chain of ifs for each of the three pairs.
