Comptage de fréquence des caractères

Indice

Un coup de pouce dans la bonne direction. La réponse complète se trouve sur la page de la solution détaillée, donc rien ci-dessous ne la révèle.

Une seule ligne, aucune branche

var counts = new Dictionary<char, int>();
foreach (char c in text) {
    counts[c] = counts.GetValueOrDefault(c) + 1;
}
return counts;

Ce qui casse si vous utilisez counts[c]++ à la place

counts[c]++ est un raccourci pour counts[c] = counts[c] + 1 -- et la moitié lecture de cette affectation composée, counts[c], lève une KeyNotFoundException la toute première fois que c apparaît, parce qu'il n'y a encore aucune entrée à lire. Cela fonctionne très bien à partir de la deuxième occurrence d'un caractère, ce qui est exactement le genre de bogue qui survit à des tests superficiels sur une entrée avec des répétitions et ne se révèle que sur une chaîne où chaque caractère est distinct.

Le cas de la chaîne vide est gratuit

foreach sur une chaîne vide n'exécute jamais son corps, donc le dictionnaire reste vide et est retourné tel quel -- aucune vérification séparée n'est nécessaire pour « il n'y avait rien à compter ».
