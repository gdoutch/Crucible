Let TryParse be the whole filter

var result = new List<int>();
foreach (var token in tokens) {
    if (int.TryParse(token, out int value)) {
        result.Add(value);
    }
}
return result;

That is the entire function. Everything this exercise is actually testing is whether you trust TryParse's judgement on edge cases rather than second-guessing it with your own pre-checks.

Do not pre-filter what TryParse already handles

Rejecting a token for having leading or trailing spaces, or for being "too long to be a real number", before ever calling TryParse throws away inputs the method would have accepted correctly on its own. Call TryParse directly on the raw token and let its boolean result be the only decision that matters.
