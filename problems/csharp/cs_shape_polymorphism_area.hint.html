Trust the interface

double total = 0;
foreach (var shape in shapes) {
    total += shape.Area();
}
return total;

That is the whole function. shape.Area() dispatches to whichever concrete type shape actually is at runtime -- that dispatch is what an interface method call *is*.

The one thing not to write

Any version of "if it's a Circle, do this; if it's a Rectangle, do that" is checking something the interface already answers for you, and it only knows about the two types the statement happened to name. A fixed test passes a third, undocumented IShape implementation specifically to catch code that branches on concrete type instead of calling Area() -- the branching version has no case for it and gets the wrong answer; the version that just calls shape.Area() was never told it needed one.
