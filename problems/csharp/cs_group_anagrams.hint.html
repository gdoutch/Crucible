The key: sort a word's own letters

string Key(string word) => new string(word.OrderBy(c => c).ToArray());

Two words are anagrams exactly when this produces the same string for both -- sorting a word's characters throws away their order, which is the one thing anagrams are allowed to differ in.

Grouping is one dictionary; ordering is a second pass

Build a Dictionary<string, List<string>> keyed by that sorted signature -- one pass over words, appending each word to the list its key maps to. That dictionary now holds the right *groups*, but not necessarily in the right *order*: walk words a second time, and the first time a given key is seen, emit that key's whole group; skip every word after that whose key has already been emitted. A HashSet<string> of "keys already emitted" is enough to tell the two cases apart.
