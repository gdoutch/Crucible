Entrelacer deux séquences, paresseusement

Indice

Un coup de pouce dans la bonne direction. La réponse complète se trouve sur la page de la solution détaillée, donc rien ci-dessous ne la révèle.

Deux énumérateurs, avancés en parallèle

using var ea = a.GetEnumerator();
using var eb = b.GetEnumerator();
bool aHasMore = ea.MoveNext();
bool bHasMore = eb.MoveNext();

while (aHasMore || bHasMore) {
    if (aHasMore) {
        yield return ea.Current;
        aHasMore = ea.MoveNext();
    }
    if (bHasMore) {
        yield return eb.Current;
        bHasMore = eb.MoveNext();
    }
}

Pourquoi la condition de boucle est ||, pas &&

while (aHasMore && bHasMore) arrête tout dès que l'un des deux côtés s'épuise -- ce qui perd le reste de la séquence la plus longue, exactement le comportement que l'énoncé exclut. || garde la boucle en marche tant que *l'un ou l'autre* côté a encore quelque chose, et les deux if indépendants à l'intérieur -- chacun ne produisant et n'avançant son propre côté que si ce côté a encore quelque chose -- sont ce qui permet à un côté de continuer à contribuer après que l'autre s'est déjà tu.

aHasMore et bHasMore sont lus, pas recalculés, à l'intérieur de la boucle -- chacun n'est mis à jour que par l'appel à MoveNext() de son propre côté, juste après que ce côté a produit une valeur.
