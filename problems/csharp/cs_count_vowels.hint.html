Count the Vowels

Hint

A nudge in the right direction. The full answer is on the worked-solution page, so nothing below gives it away.

One pass, one comparison

int count = 0;
foreach (char c in text) {
    // is c a vowel, upper or lower case?
}
return count;

Case-fold before you compare, not after

char.ToLowerInvariant(c) turns whatever case c happens to be into lower case, once, before it is compared against the five vowels. Writing the comparison against both cases instead -- c == 'a' || c == 'A' || ... -- works too, but is ten comparisons where one case-fold and five will do, and is exactly the kind of thing that is easy to only do for some of the five letters under time pressure.

ToLowerInvariant rather than plain ToLower() -- the invariant form does not depend on the machine's configured locale, which matters more for letters than it might seem: a handful of locales lower-case a small number of Unicode letters differently, and there is no reason this exercise's answer should change depending on where it runs.
