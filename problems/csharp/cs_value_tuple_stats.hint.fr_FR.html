Min, max et somme sous forme de tuple de valeurs

Indice

Un coup de pouce dans la bonne direction. La réponse complète se trouve sur la page de la solution détaillée, donc rien ci-dessous ne la révèle.

Initialisez à partir du tableau, pas d'une constante

int min = values[0];
int max = values[0];
long sum = 0;
foreach (int v in values) {
    // mettre à jour min, max, sum
}
return (min, max, sum);

Initialiser min et max à partir de values[0] signifie que chaque autre élément n'a qu'à prouver qu'il est *plus* extrême que ce qui a été vu jusqu'ici -- il n'y a pas besoin d'une branche séparée « est-ce le premier élément » à l'intérieur de la boucle.

Le débordement dont le type de retour vous prévient déjà

sum est déclaré long dans le type de retour pour une raison précise : accumuler dans une variable locale int et ne convertir en long qu'à la toute fin (return (min, max, (long)sum);) déborde pendant l'accumulation elle-même, avant même que la conversion ne s'exécute -- le transtypage arrive trop tard pour sauver une valeur déjà repartie de l'autre côté. Déclarez le total courant comme long dès sa première affectation.
