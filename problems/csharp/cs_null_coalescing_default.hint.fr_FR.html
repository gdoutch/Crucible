Un seul opérateur

C# possède un unique opérateur dont tout le travail est « ceci, sauf si c'est null, auquel cas cela » : ??. a ?? b s'évalue à a si a n'est pas null, et à b sinon -- et il fonctionne directement entre un int? et un simple int, en produisant un simple int en retour.

Ce qu'il ne faut pas utiliser

value.Value suppose que value contient effectivement quelque chose -- il lève une InvalidOperationException dès qu'il est évalué sur une valeur null, plutôt que de retourner quoi que ce soit. Si votre premier réflexe est d'écrire .Value quelque part, c'est la ligne sur laquelle revenir vérifier.

Zéro n'est pas la même chose qu'absent

Une valeur stockée de 0 a toujours HasValue == true -- ?? la retourne inchangée, comme n'importe quelle autre valeur présente. Seul un véritable null fait appel à fallback.
