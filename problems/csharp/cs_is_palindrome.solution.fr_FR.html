Vérification de palindrome

Solution détaillée

Cette page contient la réponse complète et explique pourquoi chaque partie s'y trouve.

Le code

public static bool IsPalindrome(string text)
{
    int left = 0;
    int right = text.Length - 1;

    while (left < right)
    {
        if (!char.IsLetterOrDigit(text[left])) { left++; continue; }
        if (!char.IsLetterOrDigit(text[right])) { right--; continue; }

        if (char.ToLowerInvariant(text[left]) != char.ToLowerInvariant(text[right]))
        {
            return false;
        }
        left++;
        right--;
    }
    return true;
}

Pourquoi sauter est deux vérifications séparées, pas une seule

Les deux if qui avancent au-delà de la ponctuation sont volontairement indépendants : une chaîne comme "A, ." peut avoir des caractères non alphanumériques des deux côtés à la fois (la virgule près du début, le point à la fin), et chaque pointeur doit pouvoir avancer de son côté sans attendre l'autre. Les combiner en une seule vérification « sauter si l'un ou l'autre côté est de la ponctuation » déplacerait les deux pointeurs ensemble et sauterait discrètement une lettre qui aurait dû être comparée.

Pourquoi la condition de boucle suffit comme cas de base

left < right arrête la boucle une fois que les pointeurs se rejoignent ou se croisent, et la fonction termine sur return true. Cela couvre la chaîne vide (left commence à 0, right à -1, la boucle ne s'exécute jamais) et une chaîne sans rien d'alphanumérique (les pointeurs passent outre tout et se croisent sans jamais rien comparer) de la même façon, sans vérification séparée pour l'un ou l'autre -- les deux cas signifient « rien n'a été trouvé en désaccord », ce qui est exactement ce qu'une vérification de palindrome doit en dire.

Coût

O(n) dans la longueur de `text` -- chaque pointeur n'avance (ou ne recule) jamais qu'une fois, si bien que les deux réunis visitent chaque caractère au plus une fois. Aucune copie de la chaîne n'est faite.
