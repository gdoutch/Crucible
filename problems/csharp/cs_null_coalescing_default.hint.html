Nullable Value or Fallback

Hint

A nudge in the right direction. The full answer is on the worked-solution page, so nothing below gives it away.

One operator

C# has a single operator whose entire job is "this, unless it's null, in which case that": ??. a ?? b evaluates to a if a is not null, and to b otherwise -- and it works directly on an int? against a plain int, producing a plain int back.

What not to reach for

value.Value assumes value actually holds something -- it throws InvalidOperationException the instant it is evaluated on a null value, rather than returning anything at all. If your first instinct is to write .Value somewhere, that is the line to double back to and check.

Zero is not the same as absent

A stored value of 0 still has HasValue == true -- ?? returns it unchanged, the same as any other present value. Only an actual null reaches for fallback.
