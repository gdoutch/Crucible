Palindrome Check

Worked solution

This page contains the complete answer and explains why each part of it is there.

The code

public static bool IsPalindrome(string text)
{
    int left = 0;
    int right = text.Length - 1;

    while (left < right)
    {
        if (!char.IsLetterOrDigit(text[left])) { left++; continue; }
        if (!char.IsLetterOrDigit(text[right])) { right--; continue; }

        if (char.ToLowerInvariant(text[left]) != char.ToLowerInvariant(text[right]))
        {
            return false;
        }
        left++;
        right--;
    }
    return true;
}

Why skipping is two separate checks, not one

The two ifs that advance past punctuation are independent on purpose: a string like "A, ." can have non-alphanumeric characters on both sides at once (the comma near the front, the full stop at the back), and each pointer has to be free to skip forward on its own rather than waiting for its counterpart. Combining them into one "skip if either side is punctuation" check would move both pointers together and silently skip past a letter that should have been compared.

Why the loop condition is enough of a base case

left < right stops the loop once the pointers meet or cross, and the function falls through to return true. That covers the empty string (left starts at 0, right at -1, the loop never runs) and a string with nothing alphanumeric in it (the pointers walk past everything and cross without ever comparing anything) the same way, with no separate check for either -- both are "nothing was found to disagree", which is exactly what a palindrome check should say about them.

Cost

O(n) in the length of `text` -- each pointer only ever moves forward (or backward), so the two together visit each character at most once. No copy of the string is made.
