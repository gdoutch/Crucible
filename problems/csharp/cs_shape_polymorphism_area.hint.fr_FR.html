Aire totale via une interface

Indice

Un coup de pouce dans la bonne direction. La réponse complète se trouve sur la page de la solution détaillée, donc rien ci-dessous ne la révèle.

Faites confiance à l'interface

double total = 0;
foreach (var shape in shapes) {
    total += shape.Area();
}
return total;

C'est toute la fonction. shape.Area() se répartit vers le type concret que shape est réellement à l'exécution -- cette répartition est exactement ce qu'*est* un appel de méthode d'interface.

La seule chose à ne pas écrire

Toute version de « si c'est un Circle, faire ceci ; si c'est un Rectangle, faire cela » vérifie quelque chose que l'interface vous répond déjà, et ne connaît que les deux types que l'énoncé a nommés. Un cas de test fixe fournit une troisième implémentation d'IShape, non documentée, spécifiquement pour attraper un code qui teste le type concret au lieu d'appeler Area() -- la version qui teste le type n'a aucun cas pour elle et se trompe ; la version qui appelle simplement shape.Area() n'a jamais eu besoin d'en être informée.
