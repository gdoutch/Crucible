Join a List Into a CSV Line

One call

string.Join takes a separator and a sequence, and produces exactly this: every element, separated by that separator, with none leading or trailing.

return string.Join(",", items);

Why a hand-rolled loop needs an extra step this doesn't

The natural-looking loop --

var result = "";
foreach (var item in items) {
    result += item + ",";
}
return result;

-- leaves one comma too many on the end, and needs a follow-up TrimEnd(',') or a "is this the last element" check inside the loop to fix. string.Join never has the problem in the first place, because it places the separator *between* elements rather than *after* each one.

On an empty list, string.Join returns "" directly -- no loop runs, nothing needs trimming, there is simply nothing to join.
