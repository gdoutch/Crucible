Indice

Laissez TryParse être tout le filtre

var result = new List<int>();
foreach (var token in tokens) {
    if (int.TryParse(token, out int value)) {
        result.Add(value);
    }
}
return result;

C'est toute la fonction. Ce que cet exercice teste réellement, c'est de savoir si vous faites confiance au jugement de TryParse sur les cas limites plutôt que de le remettre en question avec vos propres vérifications préalables.

Ne pré-filtrez pas ce que TryParse gère déjà

Rejeter un jeton parce qu'il a des espaces en début ou en fin, ou parce qu'il est « trop long pour être un vrai nombre », avant même d'appeler TryParse, écarte des entrées que la méthode aurait acceptées correctement toute seule. Appelez TryParse directement sur le jeton brut et laissez son résultat booléen être la seule décision qui compte.
