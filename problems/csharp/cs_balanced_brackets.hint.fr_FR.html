Empiler à l'ouverture, dépiler-et-vérifier à la fermeture

var stack = new Stack<char>();
foreach (char c in text) {
    if (c is '(' or '[' or '{') {
        stack.Push(c);
    } else if (c is ')' or ']' or '}') {
        // la pile est-elle vide, ou Pop() ne correspond-il pas à c ?
        // l'un ou l'autre signifie « non équilibré » -- return false ici même
    }
    // tout autre caractère : l'ignorer complètement
}
return stack.Count == 0;

Vérifiez avant de dépiler

stack.Peek() et stack.Pop() lèvent tous les deux une exception sur une pile vide plutôt que de retourner quelque chose à comparer -- protégez-vous avec stack.Count == 0 *avant* d'appeler l'un ou l'autre, sur une parenthèse fermante qui n'a rien d'ouvert à qui correspondre.

Une petite table associant chaque caractère fermant au caractère ouvrant qu'il attend -- ')' → '(', ']' → '[', '}' → '{' -- transforme « cette parenthèse fermante correspond-elle à ce que je viens de dépiler » en une seule recherche dans un dictionnaire et une seule comparaison, plutôt qu'une chaîne de if pour chacune des trois paires.
