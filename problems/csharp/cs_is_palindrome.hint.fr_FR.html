Vérification de palindrome

Indice

Un coup de pouce dans la bonne direction. La réponse complète se trouve sur la page de la solution détaillée, donc rien ci-dessous ne la révèle.

Deux pointeurs, qui avancent vers l'intérieur

int left = 0, right = text.Length - 1;
while (left < right) {
    // si text[left] n'est pas alphanumérique, left++ et on réessaie
    // si text[right] n'est pas alphanumérique, right-- et on réessaie
    // sinon on les compare (casse normalisée) et on avance les deux vers l'intérieur
}
return true;

Il n'est pas nécessaire de construire une nouvelle chaîne pour ne garder « que les lettres et les chiffres » -- les deux pointeurs peuvent passer outre la ponctuation sur place, un côté à la fois.

Sauter, ne pas s'arrêter

Quand text[left] n'est pas alphanumérique, le bon geste est left++; continue; -- essayer le caractère *suivant* de ce côté, pas abandonner la comparaison. Une solution qui traite un caractère de ponctuation comme un désaccord automatique échoue sur « A man, a plan, a canal, Panama » dès la première virgule.

char.IsLetterOrDigit et char.ToLowerInvariant sont les deux vérifications qui font tout le travail ici -- la première décide de ce qui compte comme « faisant partie du mot », la seconde rend la comparaison insensible à la casse.
