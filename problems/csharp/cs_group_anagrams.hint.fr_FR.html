Regrouper les anagrammes

Indice

Un coup de pouce dans la bonne direction. La réponse complète se trouve sur la page de la solution détaillée, donc rien ci-dessous ne la révèle.

La clé : trier les lettres du mot lui-même

string Key(string word) => new string(word.OrderBy(c => c).ToArray());

Deux mots sont anagrammes exactement quand cela produit la même chaîne pour les deux -- trier les caractères d'un mot élimine leur ordre, qui est la seule chose sur laquelle des anagrammes ont le droit de différer.

Le regroupement est un dictionnaire ; l'ordre est un second passage

Construisez un Dictionary<string, List<string>> indexé par cette signature triée -- un passage sur words, ajoutant chaque mot à la liste que sa clé désigne. Ce dictionnaire contient maintenant les bons *groupes*, mais pas nécessairement dans le bon *ordre* : parcourez words une seconde fois, et la première fois qu'une clé donnée est rencontrée, émettez tout le groupe de cette clé ; ignorez tout mot ultérieur dont la clé a déjà été émise. Un HashSet<string> des « clés déjà émises » suffit à distinguer les deux cas.
