Count the Vowels

Worked solution

This page contains the complete answer and explains why each part of it is there.

The code

public static int CountVowels(string text)
{
    int count = 0;
    foreach (char c in text)
    {
        char lower = char.ToLowerInvariant(c);
        if (lower == 'a' || lower == 'e' || lower == 'i'
            || lower == 'o' || lower == 'u')
        {
            count++;
        }
    }
    return count;
}

Why the case-fold happens once, up front

char.ToLowerInvariant(c) is computed a single time per character and reused for all five comparisons. The alternative -- comparing c against ten literals, five lower-case and five upper-case -- is not wrong, but it is the shape most likely to end up covering only nine of the ten under a deadline: "CRUCIBLE", all upper case, is the fixed test built specifically to catch a solution that quietly only checks lower-case letters and happens to still pass on mixed-case input by accident.

An empty string is not a special case

foreach over an empty string simply does not execute its body, and the function returns 0 without needing an explicit check. That is worth noticing rather than assuming: a solution built around indexing (text[0] to look at the first character, say) has to add the empty-string guard back in by hand, where the foreach form never needed it in the first place.

Cost

O(n) in the length of text -- one pass, one case-fold and up to five comparisons per character, no allocation.
