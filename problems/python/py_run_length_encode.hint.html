Run-Length Encoding

Hint

A nudge in the right direction. The full answer is on the worked-solution page, so nothing below gives it away.

What you are being asked for

Replace each run of identical characters with the character followed by the run length. "aaabbc" → "a3b2c1". Every run gets a number, including runs of one.

The shape

You are grouping adjacent equal characters. Two pieces of state carry you through:

  • which character the current run is made of;
  • how long it has got so far.

Walk the string. If the next character continues the run, increment the length. If it does not, the run has just ended — emit it, and start a new run from the character you are looking at.

The bug this problem is really about

The last run has no character after it to end it.

Every run is emitted when something different comes along. At the end of the string nothing different comes along, so the final run is still sitting in your two variables, unemitted, when the loop finishes.

"aaabbc" comes out as "a3b2" — right up to the last run, then silently short. Emit the final run after the loop.

This is the same shape as the classic "flush the buffer before you exit" problem, and recognising it is worth more than this exercise.

How to start

The two state variables need initial values, and there is no sensible "character that is not a character" to use. Two ways out:

  1. Handle the empty string first, then seed from text[0] and iterate over text[1:].
  2. Start with the character set to None and treat the first iteration as a special case inside the loop.

The first is cleaner. It also makes the empty-string case explicit, which you need anyway.

Building the output

Collect the pieces in a list and "".join(parts) at the end. Repeatedly doing result += ... builds a new string every time — Python strings are immutable — which is quadratic in the length of the output. For these inputs it makes no measurable difference, and it is still the habit to build.

Details from the specification

  • Runs of ten or more are written in full. "a" * 12 → "a12", not "a9a3". There is no digit limit.
  • Case is significant. "aAaa" is three runs: "a1A1a2".
  • The empty string encodes to the empty string, not to something like "0".
  • Every run gets a count, even length one. This is not the space-saving variant.

if not text:
    return ""

parts = []
run_char = text[0]
run_length = 1

for char in text[1:]:
    if char == run_char:
        run_length += 1
    else:
        # the run ended: emit it, then start a new one
        ...

# and here: the last run, which nothing ended
...

return "".join(parts)

The line you write inside the else and the line you write after the loop are the same line. If you find yourself writing it twice, that is correct and expected — it is the price of the sentinel that the end of a string does not provide.
