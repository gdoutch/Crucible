Five states and six event names make thirty pairs. Six of them are arrows; the other twenty-four return -1. That ratio is why a table beats a nest of ifs — you write what the diagram draws, and the default handles everything it does not.

Reading the notation

  • [*] --> Draft — the initial pseudostate. A new document starts in Draft; the harness does this for you.
  • Archived --> [*] — the final state. Nothing leaves it, which is why every event after archive is refused.
  • Approved --> Draft: revise — the arrow that makes this a cycle rather than a pipeline. A document can pass through Review any number of times.
