What you are being asked for

Three small integers in, one of five strings out. There is no algorithm to find — the rule is stated in full in the problem. The exercise is turning a stated rule into code that someone else could check against the rule.

Understand the rule before you type

Read it again:

  • S3 E4 C3 is ASIL D.
  • Dropping any one axis by one class drops the ASIL by one step down D, C, B, A, QM.
  • The ladder stops at QM.

Work out three cells by hand right now: S3 E4 C1, S2 E2 C2, S1 E4 C3. If you can do those, you understand the rule completely, and everything left is transcription.

Check your three

S3 E4 C1 is two steps down from D, so B. S2 E2 C2 is four steps down, which is past A, so QM. S1 E4 C3 is two steps down, so B.

Two shapes of answer, and both are correct

Write out the table. Thirty-six cells in a [3][4][3] array of strings, indexed by [severity-1][exposure-1][controllability-1]. Verbose, and a reviewer can check it one cell at a time against the standard.

Or compute it. "One step per class" is an invitation to count classes. Notice that each of the three axes contributes equally and additively — so some function of severity + exposure + controllability is going to give you the rung of the ladder directly. Work out the offset from the anchor cell and you have a two-line function.

Which one you should write is a genuinely interesting question, and the worked solution argues it out. For now: write whichever you can get right, then read the other.

The details that will fail a test

Return a string literal. return "B"; is fine — literals live for the whole program. A local array is not:

char result[4];        /* stops existing when the function returns */
strcpy(result, "B");
return result;         /* the harness reads freed stack */

It will often appear to work, which is the worst outcome. If your compiler warns about returning the address of a local variable, believe it.

The floor is not decoration. Half the table is QM. If you compute a rung and index a ladder array with it, ten of the thirty-six inputs give you a negative index — as low as -3 — and C will happily read whatever is in front of the array. Clamp before you index.

Check yourself before you press Go

  • S3 E4 C3 → ASIL D.
  • S1 E1 C1 → QM.
  • S2 E4 C3, S3 E3 C3 and S3 E4 C2 are all ASIL C — the axes are interchangeable.
  • S1 E3 C2 is QM but S1 E3 C3 is ASIL A.
  • Does anything below A come out as QM rather than as a crash?
