A Stack That Tracks Its Own Minimum

Hint

A nudge in the right direction. The full answer is on the worked-solution page, so nothing below gives it away.

Two stacks, kept in step

private Deque<Integer> values = new ArrayDeque<>();
private Deque<Integer> mins = new ArrayDeque<>();

public void push(int value) {
    values.push(value);
    // also push value onto mins, but only if it's <= mins' current top
    // (or mins is empty)
}

public void pop() {
    // pop values; also pop mins, but only if the popped value WAS the
    // current minimum
}

The comparison that has to be `<=`, not `<`

Picture pushing the same minimum value twice in a row. If the second push only goes onto `mins` when it is *strictly less* than the current top, the second occurrence is skipped -- `mins` now has only one record of a minimum that actually exists twice on `values`. Pop the more recent of the two equal values back off, and the code that checks "was the popped value the current minimum, so pop `mins` too" says yes -- and removes `mins`'s only record of it, even though an equal value is still sitting right there on `values`. The fix is one character: push onto `mins` whenever the new value is `<=` the current minimum, not only when it is strictly smaller.

`pop()` only needs to touch `mins` when the value actually being removed from `values` equals `mins`'s current top -- a popped value that was never the minimum should leave `mins` alone entirely.
