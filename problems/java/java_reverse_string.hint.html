Reverse a String (Which You Cannot Mutate)

Hint

A nudge in the right direction. The full answer is on the worked-solution page, so nothing below gives it away.

Convert, swap, rebuild

char[] chars = text.toCharArray();
int left = 0, right = chars.length - 1;
while (left < right) {
    // swap chars[left] and chars[right]
    left++;
    right--;
}
return new String(chars);

Why there is no "reverse in place" here

String has no method that changes its own characters -- there simply is no such operation to call, on any `String`, ever. text.toCharArray() is the way out: it copies the characters into a brand-new, ordinary, mutable char[] that you are free to swap elements of. `text` itself is never touched by anything that happens to that array.

An empty string and a one-character string both need zero swaps -- the same left < right loop condition that stops a longer reversal at the right place also stops immediately for either of these, with no separate check needed.
