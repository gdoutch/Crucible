Where to start

  • Size the accumulators before writing any code. Largest square, times the largest n. How many bits? Do it for the product sum too, and note it is signed.
  • Integer square root has no library function. The exact-floor requirement rules out a float sqrt, because a 64-bit value does not fit a double exactly.
  • A simple way to get an exact integer square root is to find the answer one bit at a time, from the top, keeping the running result.
  • Follow the formula literally: sum, divide (floor), then root. Taking the root first, or dividing after, gives different answers.
Still stuck?

If you want something simpler than the bit-by-bit method, a binary search for the largest r with r * r <= x is exact too. Choose the upper bound so that r * r cannot overflow while you test it.

Before you run it

Read the test names in the app. Each one is a sentence about a case you might have missed. If you can predict the output of every one by hand, your design is probably right.
