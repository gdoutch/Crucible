Sum of an Array

Hint

A nudge in the right direction. The full answer is on the worked-solution page, so nothing below gives it away.

What you are being asked for

One number out: the total of count integers starting at values. No printing — the harness already has a main that reads the array, calls you, and prints whatever you return.

The shape of it

Three moving parts, and you have met all of them before:

  • a running total, starting at zero — not at values[0];
  • a loop that visits index 0 up to count - 1;
  • adding each element into the total.

The one thing that catches people

Look at the empty array case. count is 0 and values may be NULL. Ask yourself: how many times does my loop body run, and does anything read through the pointer before that first comparison?

Written the ordinary way, this case needs no special handling at all — the loop simply never executes. Written as "start the total at the first element, then loop from 1", it dereferences a null pointer and crashes. If you find yourself adding an if (count == 0) guard, that is a sign the loop is doing something more complicated than it needs to.

Then look at "sums back to zero"

10 -10 20 -20 30 -30 totals 0. That case is there to stop you using 0 as a marker for anything — "empty" and "adds up to nothing" have to produce the same answer, because they are the same answer.

Still stuck? A bigger nudge

The whole function is a declaration, a for loop, and a return:

int total = ...;
for (int i = 0; i < count; i++) {
    /* one line here */
}
return total;

Fill in the initial value and the one line. If you would rather walk a pointer than an index, for (const int *p = values; p < values + count; p++) is the same loop and is equally safe when count is zero, because values + 0 is a legal pointer to compare even when values is null in practice.

Check yourself before you press Go

  • Does it return 0 for an empty array without touching values?
  • Does a one-element array return that element?
  • Did you write main? You should not have — the harness supplies it, and a second one will not link.
