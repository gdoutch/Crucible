GPIO Set/Clear/Toggle (Read-Modify-Write)

Hint

A nudge in the right direction. The full answer is on the worked-solution page, so nothing below gives it away.

What you are being asked for

Three operations on a register, each one a single bitwise expression against reg and mask. Get the right operator for each and there is nothing else to the function — no loop, no state to keep track of beyond what the harness already hands you.

The three operators

OperationMeaningExpression
GPIO_SETdrive masked pins highreg | mask
GPIO_CLEARdrive masked pins lowreg & ???
GPIO_TOGGLEflip masked pinsreg ^ mask

SET and TOGGLE are filled in above because they are the two people rarely get wrong. CLEAR is left blank on purpose.

The trap the problem is built around

reg & mask is not "clear the masked pins" — it is closer to the opposite. AND-ing with mask keeps only the bits that are in the mask and already set in reg, and clears everything outside the mask, which is exactly backwards from what a GPIO clear operation is supposed to do: leave the untouched pins untouched, and drop only the masked ones.

What you want is AND with the mask's complement: reg & ~mask. ~mask is 0 at every masked bit and 1 everywhere else, so ANDing it in clears exactly the masked pins and leaves every other bit exactly as it was.

One of the fixed test cases runs SET, then CLR, then TOG in sequence. Get the CLR step backwards and that test's middle line comes back wrong while the first and last lines might still look fine — a strong signal to go back and look at exactly this.

Still stuck? A bigger nudge 
unsigned int gpio_apply(unsigned int reg, enum gpio_op op, unsigned int mask)
{
    switch (op) {
        case GPIO_SET:    return reg | mask;
        case GPIO_CLEAR:  return reg & ~mask;
        case GPIO_TOGGLE: return reg ^ mask;
        default:          return reg;
    }
}

Check yourself before you press Go

  • Starting from 0: SET 0xF → 0xF, then CLR 0x5 → 0xA, not 0x5.
  • Toggling the same mask twice in a row always returns to where you started.
