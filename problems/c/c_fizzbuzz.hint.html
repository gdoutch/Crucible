FizzBuzz

What you are being asked for

Print 1 to n, one line each, replacing multiples of 3 with Fizz, multiples of 5 with Buzz, and multiples of both with FizzBuzz. Your function prints; it returns nothing.

The single decision that matters

Four outcomes, and they are not mutually exclusive in the order you will naturally write them. 15 is a multiple of 3 and a multiple of 5. If you test i % 3 first and stop there, every fifteenth line says Fizz when it should say FizzBuzz.

So the ordering rule is: most specific test first. Ask "both?" before you ask "either?". An if / else if / else if / else chain with "both" at the top gets this right by construction, because else if means "and none of the above matched".

There is a second way that also works and never has the ordering problem: build the line as a string. Start empty, append Fizz if divisible by 3, append Buzz if divisible by 5, and print the number only if the string is still empty. Slightly more code, no precedence to get wrong.

The output has to match exactly

Crucible compares stdout line by line. It normalises line endings and trailing whitespace, but not spelling, not capitalisation, and not the number of lines.

  • Fizz, Buzz, FizzBuzz — capital F, capital B, nothing else.
  • One value per line. Every line ends with \n, including the last one.
  • No header, no separators, no trailing summary.

Do not forget the boundary

When n is 0 — or negative — the correct output is nothing at all. Not a blank line; no output whatsoever. A loop counting from 1 while i <= n gives you that for free, which is a good reason to prefer it over a do…while.

Still stuck? A bigger nudge 
for (int i = 1; i <= n; i++) {
    if (/* divisible by both */) {
        printf("FizzBuzz\n");
    } else if (/* divisible by 3 */) {
        ...
    } else if (/* divisible by 5 */) {
        ...
    } else {
        printf("%d\n", i);
    }
}

"Divisible by both 3 and 5" can be written as two tests joined with &&, or as one test against their least common multiple. Both are correct; one is shorter.
