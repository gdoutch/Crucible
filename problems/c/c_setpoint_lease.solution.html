Setpoint Lease With a Safe Ramp-Down

Worked solution

This page contains the complete answer and explains why each part of it is there.

The idea

One subtraction, two comparisons, one scaled division.

int32_t lease_output(uint32_t now_ms, uint32_t last_refresh_ms,
                     uint32_t lease_ms, uint32_t ramp_ms, int32_t setpoint)
{
    uint32_t elapsed = now_ms - last_refresh_ms;
    if (elapsed <= lease_ms) {
        return setpoint;
    }
    uint32_t over = elapsed - lease_ms;
    if (over >= ramp_ms) {
        return 0;
    }
    int64_t scaled = (int64_t)setpoint * (int64_t)(ramp_ms - over);
    return (int32_t)(scaled / (int64_t)ramp_ms);
}

The three regions

elapsedRegionOutput
0 .. leaseValidsetpoint
lease .. lease + rampRampingsetpoint, scaled down
>= lease + rampFinished0

Why each line is there

  • now_ms - last_refresh_ms: unsigned subtraction wraps modulo 232, and so does the counter. The result is the true elapsed time even when now is numerically smaller. Compare the two readings directly and you fail every wrapped case.
  • The early return at over >= ramp_ms means the division only runs when ramp_ms > over >= 1. So ramp_ms is at least 2 there. A zero ramp never divides.
  • 64-bit product: 2147483647 * 4000000000 is about 8.6e18. That is below 9.22e18, the limit of int64_t. In 32 bits it overflows, which for signed values is undefined behaviour.
  • Truncation: C division truncates towards zero. -10 * 2 / 3 is -6. For a ramp this is what you want: the magnitude only ever falls, and never overshoots zero.

The slip that passes ordinary tests: doing the scaling in int32_t or uint32_t. It works for small setpoints, then fails on a large one, or on a negative one where the unsigned multiply wraps. The two extreme-setpoint tests exist to catch this.

Why a lease at all

The supervisor never has to say "stop". Silence means stop. The device needs only its own clock, so it is safe against a crashed supervisor, a dropped link, and a reset on the other side, all with no extra message. The ramp avoids a hard step to zero, which can be a shock to the grid or the load.

Point to raise

"Zero" is the safe state for a charger. For a heat pump in winter or a battery giving backup power it may not be. The lease mechanism is the same. The safe value is a per-device decision.
