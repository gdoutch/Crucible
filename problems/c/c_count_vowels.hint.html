Count the Vowels

Hint

A nudge in the right direction. The full answer is on the worked-solution page, so nothing below gives it away.

What you are being asked for

Walk a C string, and count the characters that are one of a e i o u in either case. y does not count. Everything else — spaces, digits, punctuation — is simply not a vowel.

The shape of it

A C string ends at the '\0' byte, so the loop condition writes itself. Either walk an index up to strlen, or walk the pointer itself and stop when the character it points at is the terminator. The second is the idiomatic one:

for (; *s != '\0'; s++) {
    /* is *s a vowel? */
}

s is your own copy of the pointer — advancing it does not disturb the caller's.

Deciding "is this a vowel"

Two decisions in one, and it is easier if you separate them:

  1. Normalise the case. Fold the character to lower case once, then you only have five letters to test rather than ten.
  2. Test the five. A switch with five fall-through labels, a chain of ||, or strchr("aeiou", c) — all fine. Pick whichever you find clearest.

The <ctype.h> trap. If you call tolower(*s) with a plain char, you have written undefined behaviour. On most platforms char is signed, so a byte above 127 arrives as a negative number, and tolower is only defined for values representable as unsigned char or for EOF. The fix is one cast, and it belongs on every <ctype.h> call you ever write.

Check yourself before you press Go

  • The empty string returns 0. Does your loop cope with *s being '\0' immediately?
  • rhythm returns 0. Did y sneak into your list?
  • Does AEIOU return 5? Case folding is easy to forget in one direction only.
Still stuck? A bigger nudge

Skeleton, with the decision left to you:

int count = 0;
for (; *s != '\0'; s++) {
    int c = tolower((unsigned char)*s);
    if (/* c is one of the five */) {
        count++;
    }
}
return count;

For the condition, the shortest honest version is c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u'. There is no prize for compressing it.
