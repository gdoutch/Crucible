Reverse a String In Place

Hint

A nudge in the right direction. The full answer is on the worked-solution page, so nothing below gives it away.

What you are being asked for

Rearrange the characters the caller already owns. No malloc, no second buffer, no return value — when you finish, s holds the same bytes backwards and is still a valid C string.

The shape of it

Two indices, one at each end, walking towards each other and swapping as they go. Each step swaps one pair and moves both indices inward, so a string of length n costs n/2 swaps.

i:  0  1  2  3  4
    h  e  l  l  o
    ^           ^
    i           j

Swap s[i] with s[j], then i++ and j--. Stop when they meet.

Two questions to settle before you write it

  1. Where does j start? Not at strlen(s) — that is the index of the terminator. One before it.
  2. When do you stop? while (i < j) or while (i <= j)? Think about an odd-length string: the middle character has to be swapped with itself, which is harmless, or skipped, which is also harmless. Now think about an even-length one, where i and j cross without ever being equal.

The empty string will bite you. strlen("") is 0, so length - 1 is… what, exactly? If you stored the length in a size_t — which is what strlen returns, and which is unsigned — then 0 - 1 is not -1. It is SIZE_MAX, and your loop is about to index four billion characters off the end of the buffer.

This is the single most instructive bug in the problem. Either guard the short cases before computing length - 1, or use signed indices, or compare in a way that never forms that subtraction.

Check yourself before you press Go

  • Empty string in, empty string out, and no crash.
  • One character in, the same character out.
  • abcd → dcba (even length, indices cross).
  • abcde → edcba (odd length, middle stays put).
  • Is the '\0' still at the end? If you swapped it into the middle, the string is now shorter than it was and strlen lies.
Still stuck? A bigger nudge 
size_t length = strlen(s);
if (length < 2) {
    return;                 /* nothing to do -- and this is the guard
                               that stops length - 1 wrapping around */
}
for (size_t i = 0, j = length - 1; i < j; i++, j--) {
    /* swap s[i] and s[j] using a one-character temporary */
}

A swap in C needs the temporary. There is no simultaneous assignment, so s[i] = s[j]; s[j] = s[i]; just writes the same character twice.
