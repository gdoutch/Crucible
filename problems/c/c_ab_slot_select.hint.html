Choose a Boot Slot (A/B Update with Anti-Rollback)

Hint

A nudge in the right direction. The full answer is on the worked-solution page, so nothing below gives it away.

Where to start

  • Separate the two questions. First: can this slot boot at all? Then: which of the slots that can boot is better? Write them as two steps.
  • A small helper that answers the first question for one slot keeps the second step short, and it only has to be right once.
  • Trial boots only matter for an image that is not confirmed. Read the third rule slowly.
  • Version and security version are separate fields with separate jobs. One orders releases. The other is a floor.
Still stuck?

List the cases for two slots: both bootable, one, none. Decide the return value for each before you write a line. Then check which one your tie-break lands in.

Before you run it

Read the test names in the app. Each one is a sentence about a case you might have missed. If you can predict the output of every one by hand, your design is probably right.
