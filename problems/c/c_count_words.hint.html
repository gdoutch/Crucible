Count the Words

Hint

A nudge in the right direction. The full answer is on the worked-solution page, so nothing below gives it away.

What you are being asked for

How many runs of non-space characters are in the line. Spaces and tabs separate words; everything else, punctuation included, is part of a word.

The wrong first instinct

Almost everybody starts with "count the spaces and add one". Try that against these four inputs before writing any code:

InputSpacesSpaces + 1Right answer
hello world122
hello   world342
 hello121
     560

It works for exactly one of them. The problem is that a separator is not one character, it is a run of them, and the ends of the string are special.

The shape that does work

Stop thinking about separators and think about transitions. At every character you are in one of two states — inside a word, or not — and a word begins at the moment you go from outside to inside. Count those moments and you have counted the words, with no special cases for the start or the end of the line.

So you need one extra variable besides the counter: a flag remembering which state you are in. It starts as "outside", because before the first character you are not inside anything.

The four things that happen at each character

Current charCurrently inside?Do what
space or tabyesthe word just ended
space or tabnonothing
anything elsenoa word just started — this is the one you count
anything elseyesnothing, still in the same word

Two of those four rows do nothing at all, which is why the finished loop is shorter than this table suggests.

Still stuck? A bigger nudge 
int words = 0;
int inside = 0;

for (; *s != '\0'; s++) {
    if (/* *s is a space or a tab */) {
        inside = 0;
    } else if (!inside) {
        inside = 1;
        words++;
    }
}
return words;

Note that the else if already covers "not inside" — the fourth row of the table needs no branch, because falling off the end of the if chain is doing nothing.

Check yourself before you press Go

  • Empty string → 0.
  • Five spaces and nothing else → 0. You never enter a word, so you never count one.
  • Leading and trailing spaces do not change the count.
  • Tabs separate words too, not just spaces.
