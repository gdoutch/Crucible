Match a Simplified Regular Expression ('.' and '*')

Hint

A nudge in the right direction. The full answer is on the worked-solution page, so nothing below gives it away.

Ask one question at each position

Given where you are in s and where you are in p, there is exactly one thing to check first: does the pattern's next atom (one letter, or .) match the string's next character? Call that first_match -- it is false immediately if s has run out of characters, whatever the pattern says.

Then branch on what follows the atom in the pattern

if next atom in p is followed by '*':
    return  match(s, p skipping "atom*")           /* zero reps    */
         or (first_match and match(s + 1, p))        /* one more rep */
else:
    return first_match and match(s + 1, p + 1 atom)

Notice the second branch of the `*` case recurses on the same pattern position, not past it -- that is what lets `a*` consume any number of `a`s one at a time rather than just zero or one.

The base case people forget to check first

If the pattern is exhausted, the match succeeds only if the string is also exhausted. It is tempting to write this check after the `*`-lookahead logic instead of before it -- but looking ahead to "is the next pattern character a `*`" when there is no next pattern character at all is exactly the out-of-bounds read that base case exists to prevent.

Proving the anchoring is right

regex_match("aa", "a") should be false. If your implementation says true, it is finding "a" as a prefix of "aa" rather than requiring the whole string to be consumed -- check that the recursion's base case really does require both `s` and `p` to be empty together, not just `p`.
